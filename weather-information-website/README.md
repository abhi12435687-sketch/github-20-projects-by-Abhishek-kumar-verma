# WeatherGPT

Finished local WeatherGPT project, including the AI chat, dark-mode contrast improvements, and searchable location dropdown.

## Run

Double-click `START_WEATHERGPT.bat`. It starts the local server and opens the working AI chat at `http://127.0.0.1:8766`.

Do **not** open `index.html` directly by double-clicking it: it needs the local Python server (`app.py`) to keep the API key private and provide the `/api/chat` AI endpoint.
